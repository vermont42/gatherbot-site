GatherBot Privacy Policy

Last updated October 17, 2026

GatherBot is a private household assistant used by one family. It is not offered to the public. This policy describes what GatherBot does with the Google account data of the family member who authorizes it.

What GatherBot accesses

With the account holder's permission, GatherBot uses these Google permissions and no others:

  • Gmail, read-only: to search and read email so it can summarize messages and answer questions about them.
  • Gmail, compose: to save draft replies in the account's Drafts folder. GatherBot never sends email. The account holder reviews and sends every draft.
  • Google Calendar events: to read events on the family's calendars and to add or remove events on the family calendar when a family member asks.
  • Google Calendar list, read-only: to see which calendars the account has, so GatherBot uses the right one.

GatherBot does not ask for full Google Calendar access, so it cannot change who a calendar is shared with or delete a calendar.

How the data is used

Google data is used only to provide GatherBot's features to the family: answering their questions, summarizing email, drafting replies and keeping the calendar current. It is not used for advertising, is not sold, and is not used to train AI models.

Where the data goes

  • GatherBot runs on a private server rented from a cloud hosting provider. The Google sign-in token and GatherBot's working notes are stored there.
  • To understand requests and write replies, GatherBot sends the relevant email or calendar text to an AI model provider (OpenAI) as part of each request.
  • Answers are delivered to family members in a private Slack workspace.

Google data is not shared with anyone else, except where required by law.

Google API Services User Data Policy

GatherBot's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

The account holder can revoke GatherBot's access at any time at myaccount.google.com/permissions. When access is revoked or GatherBot is shut down, the stored sign-in token is deleted.
